# Prime Agent project description and semantic scope

Prime Agent is a standalone professional knowledge collection and enrichment
project in the Arcanada ecosystem. Its intended output is a traceable professional
knowledge dataset that remains usable independently of the collection engine and
can support future Talomnia Atlas integration.

## Intended work

The project is being developed to collect occupational and skill knowledge from
eligible sources, retain provenance, enrich selected concepts and map the results
to complete native canonical knowledge artifacts. It reuses the existing Knowledge
Contract schemas, validation and consumer meaning; it does not define a simplified
replacement for native artifacts.

The planned generation path uses DeepSeek. JEV provides a separate classification
path. A generated or classified result is a candidate for validation, not proof of
correctness, complete coverage or admitted knowledge. Collection rights, quality,
source traceability and operation-level authorization remain separate conditions.

## Current delivery state

Prime is in development. This description does not claim an installed collection
service, successful recurring collection, measured live quality or complete
professional coverage. Talomnia Atlas implementation remains paused; future data
integration is an intended consumer relationship, not an active runtime mount.

## Scope and ownership boundaries

The Arcanada workspace projects registry owns project membership and location.
Prime's existing private implementation and knowledge repositories retain their
separate source and data custody. Private knowledge bodies, native Skills,
Blueprints, Constraints, operational policies and issuance records remain with
existing authorized owners and are excluded from this public description.

Canon owns this disclosure-safe descriptive projection. Native Knowledge Contract
meaning and admission stay with their existing owners. This draft transfers no
writer, issuer, identity, promotion, publication or runtime authority. It is not an
admitted native project charter, an AuthoringGrant or a compiled Canon release.
The project scope names the description; parent bindings and private authority
closure must be supplied and validated through their existing native routes.
