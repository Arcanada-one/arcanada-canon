# Portfolio contract

No production models are approved by this bootstrap. Consume exact Model Connector catalog/model/provider/freshness/pricing identities, then qualify on frozen Canon golden cases and data-handling policy. Standard production requires at least three actual model families and two providers; aliases or modality labels do not prove family diversity. Privacy constraints take precedence. Unavailable quality/identity/price evidence holds the candidate rather than silently substituting a model. This adoption's independent contexts are not a production diversity benchmark.
