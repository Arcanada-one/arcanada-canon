# Propose a Canon change

1. Read the adopted integration plan and decision applicable to the intended artifact kind.
2. Branch from current origin/main in a fresh task-owned clone. Record input source revisions and scope authority; keep credentials outside Git.
3. Edit a derived candidate with source/meaning links. Preserve original specifications and prompts byte-for-byte.
4. Run the applicable schema, source fidelity, ACL and golden checks. Request an independent artifact-only agent review with input hashes and reviewer_incarnation.
5. Secret-scan, rebase from current upstream, push and merge through a PR with exact-head checks and resulting-main readback.

A merged source candidate is not an active policy. Promotion requires the separate admitted compiler, portfolio, signed release, current authority/revocation and actual consumer gates. No bootstrap command in this repository performs promotion.
