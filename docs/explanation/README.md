# Why one repository first

The operator requested one new arcanada-canon repository and a home for continuing Canon work. A federation becomes useful when authority, confidentiality or release cadence differs. Explicit source IDs, root classes and dependency pins preserve that future choice without creating four empty authorities today. Full specification conformance still requires an independently authorized second-source fixture.

A compact Context Capsule is the per-execution view. A complete immutable bundle and Meaning Ledger keep the source semantics auditable. Search helps find material; a ranked search result cannot establish that all mandatory constraints were considered. KC2's descriptive charter orientation remains distinct from normative policies.

Legacy mandates and runtime routers stay in place until per-fragment semantic reconciliation, shadow parity and one-class/one-consumer cutover. No directory copy transfers authority. Previous verified non-revoked releases/read mappings provide the rollback boundary.
